# strata — Digital Stratigraphy Engine

```
   ╔══════════════════════════════════════╗
   ║     STRATA : DIGITAL CORE SAMPLE     ║
   ╚══════════════════════════════════════╝
```

**Strata** is a digital paleontology tool. It treats your filesystem like geological sediment — file extensions become minerals, creation dates become eras, and size becomes mass. It produces a visual "core sample" revealing the hidden strata of your digital life.

## Concept

Just as geologists read Earth's history through rock layers, Strata reads your digital history through file patterns. Sedimentary layers form over time as files accumulate. Each file type is a distinct mineral with its own color and crystal structure:

- `.ps1` → **Verdant Mica** (green)
- `.rs` → **Rust Hematite** (red iron)
- `.js` → **Amber Resin** (golden)
- `.py` → **Pyrite Gold** (fool's gold)
- `.exe` → **Magma Core** (volcanic red)
- `.md` → **Chalk** (soft white)

## Usage

```powershell
.\strata.ps1                         # Profile current directory
.\strata.ps1 -Path C:\Users\You\src  # Profile specific site
.\strata.ps1 -Depth 5               # Dig deeper
.\strata.ps1 -Animate               # Watch the excavation
```

## Output

- **Strata column**: layered visualization of each geological era (Holocene → Paleocene)
- **Fossil distribution map**: 2D grid where each pixel is a file, colored by mineral type
- **Mineral key**: complete legend of all file types discovered

Every filesystem produces a unique cross-section. Run it on different directories to compare their geological signatures.
